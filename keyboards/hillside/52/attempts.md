class="header-anchor" href="#firmware" aria-label="Permalink to &quot;Firmware&quot;">​</a></h1><p><a href="https://docs.qmk.fm/#/" target="_blank" rel="noreferrer">QMK</a> is a popular free and open-source keyboard firmware. All of our keyboards are supported by QMK and VIA / Remap for dynamic key assignments and layering. The firmware provides features that streamline pointing device usage, which is a focus of the store. These include:</p><ul><li>scaled movement: transforms the x/y that&#39;s read from the pointing device. This is useful for large screens or cases where fine grained move is necessary. Supports two modes: default and &quot;sniping&quot;, each with its own multiplier.</li><li>drag scroll mode: convert mouse moves into scrolling (similar to middle mouse click).</li><li>buffered scroll: slows down scrolling for more control.</li><li>scroll lock: constraints scrolling to vertical / horizontal only.</li></ul><p>All of the above can be adjusted on the fly without flashing a new firmware. See <a href="#features">below</a> for a more in-depth walkthrough.</p><details class="details custom-block"><summary>Keyball/Killer Whale</summary><p>These keyboards have a firmware specific to them with similar features as above.</p></details><div class="info custom-block"><p class="custom-block-title">INFO</p><p>Fully built keyboards already come flashed and tested. You can use these instructions to learn how to flash your own keymap / custom logic onto the standard firmware we provide.</p></div><div class="danger custom-block"><p class="custom-block-title">DANGER</p><p>Avoid connecting / disconnecting the TRRS cable when the keyboard is powered. This can short the GPIO pins of the controllers.</p></div><h2 id="source-code" tabindex="-1">Source Code <a class="header-anchor" href="#source-code" aria-label="Permalink to &quot;Source Code&quot;">​</a></h2><p>The source code for all keyboards can be found on the <code>hk-master</code> branch of <a href="https://github.com/holykeebs/qmk_firmware" target="_blank" rel="noreferrer">https://github.com/holykeebs/qmk_firmware</a>. This repo is periodically kept up to date with main QMK.</p><p>Most of the custom logic is contained to <code>users/holykeebs</code> and the specific keyboard you&#39;re flashing for. Some scaffolding changes were also required in core QMK, but these are quite limited.</p><p>If you wish to bring the changes into your own fork of QMK, please make sure you&#39;ve copied them all. If your controller is already flashed with a QMK firmware, you can simply double tap the reset button on the keyboard itself.</li></ul><p>The <a href="https://github.com/holykeebs/qmk_compiled/releases/download/latest/commands.txt" target="_blank" rel="noreferrer">commands.txt</a> has a list of file name to the make command that produced it and can be used as a reference.</p><div class="danger custom-block"><p class="custom-block-title">DANGER</p><p>Avoid connecting / disconnecting the TRRS cable when the keyboard is powered. This can short the GPIO pins of the controllers.</p></div><h2 id="compiling" tabindex="-1">Compiling <a class="header-anchor" href="#compiling" aria-label="Permalink to &quot;Compiling&quot;">​</a></h2><p>Since many of our keyboards share common features such as OLED / Pointing Devices, these are supported via the <a href="https://docs.qmk.fm/#/feature_userspace" target="_blank" rel="noreferrer">Userspace feature</a>: this allows the logic to be separated from a specific keyboard / keymap. The trackball is different on each layer.</p><details class="details custom-block"><summary>Details</summary><p>Layer 0: Trackball scrolls the page. For me, my most common mouse action was scrolling in a web browser etc, so this is the default. Works perfectly for this task.</p><p>Layer 1: Trackball presses arrow keys. I also really like this for moving inside text fields and it feels really good with the clicks of the trackball. This is how it was used on older mobile phones, and it is really good at this.</p><p>Layer 2: Trackball is mouse. Out of the box, the pimoroni is a pretty bad mouse, needing you to drag it edge-to-edge about 5 times to move across your screen. If you just up the sensitivity then it isn’t accurate enough to do things like select individual buttons.
